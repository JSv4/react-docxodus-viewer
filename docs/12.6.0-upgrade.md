# Docxodus 12.6.0 integration

The browser engine and optional `@docxodus/export` companion are pinned to
12.6.0. Reinstall dependencies and copy the matching runtime with
`npx rdv-copy-runtime public/docxodus` (or `npm run sync:wasm` in this repository).
The checked-in WASM, worker, export bundle, and manifest are the unmodified npm
assets. Do not mix assets from earlier releases.

## Formatted typing

The canvas now uses the supported `session.replaceMatch(match, text, format)`
operation for a contiguous replacement or insertion at a native run boundary,
including an empty paragraph. Docxodus applies text and formatting in one
undo/version unit and rolls back both on failure, without the full-package
checkpoint and hash required by `executeBatch`.

The format applies only to new text. A pure insertion inside an existing run
still uses the public atomic batch: the native span API requires a neighboring
character to address that position, and applying the typing format to that
character would alter existing text. Disjoint drafts and compound structural
edits also retain atomic batches. The library does not patch the native runtime.

Local text-plus-format operations reuse the existing live block renderer and
metadata caches. Code formatting and custom format serialization take the
conservative path because they may change document-wide style definitions.

## API and rendering compatibility

The root, engine, worker, browser-export, and server entries continue to re-export
the complete upstream APIs. The new document-level `getComments` reader is
available from the engine and the upstream worker proxy.

The upstream pagination source is byte-identical to 12.4.1 (SHA-256
`2b67cf77f5383db0871647e8c40ca367e1c79cfb3f996120edbf6d7c707e31c0`).
The native page-map contract is also unchanged. The cooperative adapter was
regenerated against the published 12.6.0 package; native differential tests
remain the compatibility check.

See [performance measurements](performance.md) for reproducible workloads,
results, and remaining latency limits.
